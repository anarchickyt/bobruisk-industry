# Бобруйск промышленный и инженерия: как, где, сколько

Сайт-презентация о 12 предприятиях Бобруйска: какие инженеры им нужны, вакансии и зарплаты, где учиться.

**Сайт:** https://anarchickyt.github.io/bobruisk-industry/

## Что внутри

- **Заводы** — все предприятия на одном экране; у каждого своя страница: факты, фото, инженерные специальности, вакансии, где учиться.
- **Карта** — Яндекс Карта с расположением предприятий.
- **Профессии** — поиск по всем инженерным направлениям.
- **Зарплаты** — вилки зарплат из открытых вакансий (ноябрь 2026).
- **Где учиться** — маршрут «колледж → завод → вуз» для каждого предприятия, профильные вузы и колледжи.

## Как запустить

Сборка не нужна — это статический сайт. Откройте `index.html` в браузере.

## Как обновить данные

Все тексты, специальности, вакансии и зарплаты лежат в [`assets/js/data.js`](assets/js/data.js). Фото предприятий — в `assets/img/<предприятие>/`.

Если Яндекс Карта перестанет загружаться, получите бесплатный ключ JavaScript API на [developer.tech.yandex.ru](https://developer.tech.yandex.ru) и впишите его в константу `YANDEX_API_KEY` в [`assets/js/app.js`](assets/js/app.js).

## Источники

По материалам презентации «Бобруйск промышленный и инженерия: как, где, сколько». Сведения о вакансиях — из открытых источников (Rabota.by, ГСЗ, сайты предприятий) на ноябрь 2026 года и могут меняться.
